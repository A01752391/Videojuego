Créditos

Pawned v1.0

Un innovador juego de ajedrez con power-ups únicos que revoluciona la experiencia clásica del ajedrez. Desarrollado con pasión y dedicación para ofrecer entretenimiento estratégico de alta calidad.

Equipo de Desarrollo

Equipo Pawned
Desarrollo del Juego y Diseño General
Desarrollador Principal
Lógica del juego, Power-ups, Sistema de combate
Diseñador UI/UX
Interfaz visual, Arte, Iconografía
Ingeniero de Datos
Base de datos, Leaderboard, Estadísticas

Características Principales

  • Sistema Roguelike: Posiciones de piezas aleatorias en cada ronda
  • 10 Power-ups Únicos: Desde escudos protectores hasta portales dimensionales
  • Sistema de Puntuación Dinámico: Gana puntos por capturas y desbloquea poderes
  • Leaderboard Global: Compite con jugadores de todo el mundo
  • Detección Inteligente: Jaque mate, ahogado y situaciones especiales
  • Modalidad Mejor de 3: Rondas épicas con mecánicas de compensación
  • Efectos Visuales: Animaciones y partículas que mejoran la experiencia
  • Audio Inmersivo: Efectos de sonido personalizados

Tecnologías Utilizadas

HTML5 CSS3 JavaScript ES6+ Node.js Express.js MySQL Git JSON

Recursos y Multimedia

  • Gráficos Originales: Piezas de ajedrez y power-ups diseñados específicamente
  • Efectos de Sonido: Audio personalizado para movimientos y activaciones
  • Interfaz Responsiva: Optimizada para diferentes tamaños de pantalla
  • Iconografía Intuitiva: Símbolos claros para facilitar el aprendizaje
